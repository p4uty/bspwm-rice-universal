¡Bienvenido a bspwm!

Este mensaje solo aparece la primera vez. Algunos atajos para empezar
(super = tecla Windows):

    super + c              Hoja con todos los atajos (requiere eww)
    super + Enter          Abrir la terminal
    super + Espacio        Menú de aplicaciones
    super + x              Cerrar la ventana
    alt + Espacio          Cambiar de tema (emilia, cristina, h4ck3r)
    super + alt + w        Elegir wallpaper (se guarda por tema)
    super + 1..0           Cambiar de escritorio
    super + alt + t        Elegir terminal (kitty / alacritty)
    super + alt + o        Terminal desplegable (scratchpad)
    super + alt + s        Capturas de pantalla
    super + alt + p        Menú de apagado
    super + alt + h / u    Ocultar / mostrar la barra
    super + alt + r        Reiniciar bspwm

Todos los atajos están en ~/.config/bspwm/config/sxhkdrc; puedes editarlos
y recargarlos con super + Escape.

Documentación y problemas: consulta el README del repositorio.
