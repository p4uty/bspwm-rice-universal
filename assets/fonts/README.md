# Fuentes incluidas

`install.sh` copia estas fuentes a `~/.local/share/fonts/`. Proceden del repositorio
original de [gh0stzk/dotfiles](https://github.com/gh0stzk/dotfiles) y cada una
mantiene **su propia licencia**, independiente de la GPL-3.0 del resto del proyecto.

| Fuente | Se usa en | Proyecto / licencia |
|---|---|---|
| Font Awesome 6 Free (Solid) | iconos de polybar, eww | [fontawesome.com](https://fontawesome.com/license/free), SIL OFL 1.1 |
| Material Design Icons Desktop | iconos de polybar, rofi, eww | [Pictogrammers](https://pictogrammers.com/docs/general/license/) |
| MesloLGS NF | polybar (emilia, cristina) | [romkatv/powerlevel10k-media](https://github.com/romkatv/powerlevel10k-media), Apache 2.0 |
| Iosevka Nerd Font | disponible para los temas | [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts), SIL OFL 1.1 |
| Maple Mono NF | Neovim, eww (tarjeta de perfil) | [subframe7536/maple-font](https://github.com/subframe7536/maple-font), SIL OFL 1.1 (ver `MapleMono-NF/LICENSE.txt`) |
| Bebas Neue | eww (hoja de atajos, tarjeta de perfil) | [Google Fonts](https://fonts.google.com/specimen/Bebas+Neue), SIL OFL 1.1 |
| Phosphor | disponible para los temas | [phosphor-icons](https://github.com/phosphor-icons), MIT |
| Cozette | disponible para los temas | [slavfox/Cozette](https://github.com/slavfox/Cozette), MIT |
| scientifica | disponible para los temas | [oppiliappan/scientifica](https://github.com/oppiliappan/scientifica), SIL OFL 1.1 |
| cherry | disponible para los temas | [turquoise-hexagon/cherry](https://github.com/turquoise-hexagon/cherry) |
| Clarity City | disponible para los temas | [vmware/clarity-city](https://github.com/vmware/clarity-city), SIL OFL 1.1 |
